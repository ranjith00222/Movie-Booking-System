# Movie Ticket Booking System

A simple Python-based console application for booking movie tickets in Hyderabad theatres.

## Overview

This project allows users to:

- View available movies and show timings
- View theatre locations in Hyderabad
- Select a theatre and movie
- Choose seats from a seat map
- Book up to 5 tickets at a time
- View existing bookings
- Cancel a booking and receive a refund

## Features

- Movie list with show times and prices
- Theatre list with locations
- 5x6 seat layout per theatre and movie
- Seat validation to avoid double-booking
- Booking ID tracking
- In-memory data storage while the program is running

- Data is reset when the program exits.
- The seat layout is predefined for each theatre and movie combination.
